# RWKV Training Guide — Interactive Learning

> [English](README_EN.md) · [中文](README.md)

A progressive learning staircase from zero to building your own RWKV training framework. Every formula comes with a hands-on interactive lab.

## Curriculum (14 chapters · 50+ lessons)

| Stage | Chapters | Topics |
|-------|----------|--------|
| **Math Foundation** | Linear Algebra · Calculus · Probability | Matrices, gradients, distributions |
| **ML Fundamentals** | Optimization · Foundation Networks | SGD, backprop, RNN/LSTM |
| **Sequence & Attention** | Seq2Seq · Attention · Transformer | Self-attention, multi-head, positional encoding |
| **RWKV Theory** | Architecture · TimeMix · WKV | Core RWKV innovations |
| **Engineering** | Training Framework · Data · Distributed | Write training code from scratch |
| **Frontiers** | Paper Reading · Future Directions | Latest research |

## Interactive Labs

12 hands-on visual labs: gradient descent simulator, attention heatmap, RNN unroll, WKV stepper, tokenizer demo…

## Stack

React 19 + TypeScript + Vite 7 + Tailwind CSS + shadcn/ui + KaTeX

## Quick Start

```bash
npm install
npm run dev
```
